# Spontaneous time-reversal symmetry breaking by optical-phonon lasing

Codes for generating plots on spontaneous time-reversal symmetry breaking by optical-phonon lasing.

The file [`calc.ipynb`](https://github.com/solihinn17/symm-break-circ-phonon/blob/main/calc.ipynb) contains the analytical notes and full simulation codes used in the paper, with all details included. To reproduce the plots without rerunning the calculations, please use [`plot.ipynb`](https://github.com/solihinn17/symm-break-circ-phonon/blob/main/plot.ipynb).
